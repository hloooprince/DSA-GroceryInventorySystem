# Grocery Inventory System

## About the Project
This is a simple Java-based Grocery Inventory System developed as part of my Data Structures and Algorithms (DSA) project.

The main purpose of this project is to manage grocery items, track available stock and make inventory management easier.

## Features
- Add new grocery items.
- Automatically generate Product IDs.
- Sell items and update stock.
- Display items alphabetically by name.
- Generate a low-stock report.
- Prevent selling more items than available.
- Save and load inventory using file handling.

## Technologies Used
- Java
- ArrayList
- HashMap
- Bubble Sort
- File Handling
- Object-Oriented Programming

## How to Run
1. Install Java JDK.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Java IDE.
4. Compile the program:

   `javac GroceryInventorySystem.java`

5. Run the program:

   `java GroceryInventorySystem`

## Project Structure
- GroceryInventorySystem.java – Main Java program.
- Project_Report.pdf – Project documentation.
- inventory.txt – Inventory data file generated by the program.

## Learning Outcomes
Through this project, I learned how to use ArrayList and HashMap, implement Bubble Sort, work with file handling and apply DSA concepts to a real-world problem.
